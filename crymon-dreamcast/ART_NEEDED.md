## Instructions for generating replacement art

1. Draw/generate a PNG matching the **pixel size** given for each row
   below (or any larger size with the same aspect ratio -- everything
   is downscaled at build time, never upscaled).
2. Style: match the existing CryMon art in `public/sprites/` -- simple,
   readable silhouettes, flat-ish shading, small enough to read at 24-92px
   on screen. Battle sprites (`monsters/<name>/`) are the most detailed;
   world sprites (`npc/<name>-N.png`) and item icons are simpler.
3. Background: fully transparent (alpha channel), not a solid color --
   anything under alpha 128 is treated as see-through at build time.
4. Save the PNG at **exactly** the "expected path" column below, rooted
   at `public/sprites/` inside a checkout of `xenodorian/CryMon` (the
   same repo this port's art already comes from). That's the only path
   `tools/gen_sprites.py <path-to-CryMon-checkout>` ever looks at --
   dropping a real file there automatically replaces the placeholder
   next time sprites are regenerated, no code changes needed.
5. Monsters and NPCs need one file per frame (1-4); it's fine for all 4
   to be pixel-identical at first (no animation) -- a real idle cycle can
   follow later.
